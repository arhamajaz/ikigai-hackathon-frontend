3-Minute Sideload Quickstart

Follow these instructions to load SentinelEdge into Chrome, Brave, or Edge without external web store dependencies:

  1. Download and extract the SentinelEdge-v2.4.zip archive.
  2. Navigate to chrome://extensions in your browser.
  3. Enable Developer Mode toggle (top right corner).
  4. Click Load Unpacked and select the extracted folder.
