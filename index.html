🔒 3. Privacy & Declarations
Single-Line Privacy Summary:
SentinelEdge handles website content 100% on-device in browser memory. Zero prompt content, clipboard payloads, or intercepted tokens are collected, stored externally, or transmitted to remote servers.

Chrome Web Store Declarations:

  • Not sold to third parties: User data is strictly isolated on-device.
  • Not used for unrelated purposes: Inspection operates solely for client-side DLP.
  • Not used for creditworthiness: No credit/lending evaluations performed.

Data Categorization Handled:

  • Website Content: Inspected locally in DOM memory only; never exfiltrated.
  • Local Storage (chrome.storage.local): Stores numerical counters and timestamps only.
